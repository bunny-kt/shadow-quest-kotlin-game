# 🗝️ Shadow Quest — Dungeon Escape

Welcome to **Shadow Quest**, a beginner-friendly adventure game built with Kotlin!

Explore mysterious dungeon rooms, collect coins, discover treasures, avoid traps, and try to escape.

## 🎮 Features

- 🏰 Explore dungeon rooms
- 🪙 Collect coins and treasures
- 🧪 Discover health potions
- ⚠️ Avoid traps and challenges
- ❤️ Manage your health and survive

## 🛠️ Built With

- Kotlin
- Console-based programming

## ▶️ How to Run

1. Open the `Main.kt` file.
2. Copy the code into [OneCompiler Kotlin](https://onecompiler.com/kotlin/45723xnt5).
3. Click Run and follow the instructions.

- `Main.kt` — Main game program
